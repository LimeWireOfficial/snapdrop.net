# snapdrop.net

Source code of the client served at [snapdrop.net](https://snapdrop.net) — exactly the files the site serves, updated automatically on every deploy.

Snapdrop sends files directly between devices with WebRTC. Files picked for a direct transfer travel peer-to-peer and do not pass through our servers. Optional cloud links (for devices that are not online at the same time) are provided by [LimeWire](https://limewire.com).

## Running your own copy

The pairing (signaling) server is not part of this repository and only accepts connections from snapdrop.net. To run your own copy you need your own signaling server — for example, the server from the original Snapdrop project.
